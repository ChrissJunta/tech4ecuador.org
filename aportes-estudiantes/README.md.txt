# Aportes de estudiantes

Esta carpeta contiene los aportes desarrollados por los estudiantes
durante la actividad de colaboración con Git y GitHub.

## Reglas de trabajo

1. Cada estudiante debe crear una rama propia.
2. No se debe trabajar directamente sobre la rama main.
3. Cada estudiante debe crear una carpeta con su nombre y apellido.
4. Los nombres deben escribirse en minúsculas, sin espacios ni tildes.
5. No se deben modificar las carpetas de otros estudiantes.
6. Cada aporte debe incluir al menos un archivo README.md.
7. Los cambios se entregarán mediante un Pull Request.
8. El propietario del repositorio revisará y aprobará los aportes.

## Estructura esperada

aportes-estudiantes/
└── nombre-apellido/
    ├── README.md
    ├── aporte.html
    └── assets/
